# 신규 기능 작업 규칙

신규 기능 구현 시 다음 절차를 따른다.

## 구현 전

먼저 다음을 정리한다.

1. 요구사항 해석
2. 기대 동작
3. 영향 받는 Module/File
4. 기존 유사 구현
5. 구현 전략
6. DB 변경 여부
7. API Contract 변경 여부
8. UI/파일 포맷/외부 연동 영향
9. 호환성 및 회귀 위험
10. 테스트 방법

## 구현 원칙

- 기존 Architecture와 Pattern을 먼저 사용한다.
- 요구사항에 필요하지 않은 기능을 추가하지 않는다.
- 새로운 Dependency 도입은 필요성을 설명한다.
- Public Contract 변경은 명확히 보고한다.
- 기존 Client 또는 구버전과의 호환성을 고려한다.

## 완료 시

- 구현 내용
- 수정 파일
- DB/API 영향
- 테스트 결과
- 회귀 위험
- 추가 작업 필요 여부
를 보고한다.
